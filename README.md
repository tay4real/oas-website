# OAS Solutions Ltd — Company Website

The official website of **OAS Solutions Ltd**, a Nigerian technology company focused on software engineering, digital solutions, AI/ML and technology-driven product development.

🌐 **Live Website:** https://oassolutions.com.ng/

---

## Overview

This repository contains the source code for the OAS Solutions Ltd corporate website.

The website serves as the company's public-facing digital presence, providing information about the company, its technology services, products, projects and areas of expertise.

The implementation intentionally uses a lightweight frontend architecture rather than a JavaScript framework, as the requirements of the corporate website did not justify the additional complexity of a framework-based application.

---

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Cloudflare

---

## Architecture

The website is primarily a static frontend application consisting of:

- HTML pages
- CSS styling
- JavaScript functionality
- Static assets
- SEO-related files
- Privacy and Terms pages
- Sitemap
- Robots configuration

The site is deployed through **Cloudflare**.

---

## Deployment

The production website is hosted using Cloudflare infrastructure.

**Production URL:**

https://oassolutions.com.ng/

---

## Key Characteristics

- Lightweight frontend architecture
- Responsive web design
- Static HTML/CSS/JavaScript implementation
- Cloudflare deployment
- SEO-friendly sitemap and robots configuration
- Privacy and Terms pages
- Web application icons and favicon assets

---

## Engineering Approach

The project follows a simple principle:

> **Use the simplest architecture that appropriately solves the problem.**

Because the OAS Solutions corporate website primarily serves informational and presentation purposes, a lightweight HTML/CSS/JavaScript implementation provides the required functionality without introducing unnecessary framework complexity.
